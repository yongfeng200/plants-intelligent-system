如何训练模型？

  1. 方法一：使用Python脚本训练

    在命令行中运行训练脚本，适合批量训练

    # 训练葡萄病害模型
    python train_grape_disease.py

    # 训练芒果叶片病害模型
    python train_mango_leaf_disease.py

    # 训练芒果品种识别模型
    python train_mango_variety.py

  2. 方法二：使用Jupyter Notebook（推荐）

    交互式训练，可以实时查看训练过程和结果

    # 启动Jupyter Notebook
    jupyter notebook

    # 然后打开对应的notebook文件：
    # - GrapeDiseaseTraining.ipynb
    # - MangoLeafDiseaseTraining.ipynb
    # - MangoVarietyTraining.ipynb

  3. 方法三：下载预训练模型（如果可用）

    从项目仓库或云存储下载已训练好的模型文件

    # 将模型文件放置到项目 models/ 目录
    # 确保文件名正确：
    # - grape_disease_model.pth
    # - mango_mdcn_best_checkpoint.pth
    # - mango_variety_best_checkpoint.pth
    # - grape_segment_model.pt

  4. 检查模型是否加载成功

    训练完成后，刷新此页面或重启服务器

    # 重启 Flask 服务器
    python py/main.py

    # 或访问健康检查 API
    curl http://127.0.0.1:5000/health
提示：训练时间根据硬件配置不同，通常需要30分钟到2小时。使用GPU可以大幅加速训练过程。
